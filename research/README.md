# Gear research applications

Research protocols and participant task definitions live here so that the
core SDK, connectors, and product UI remain independent from a particular
evaluation scenario.

The `agent-grid-planning/` study currently reuses scenario documents and
images from `data/AgentGridPlanning/` while its task assignment is configured
locally in `agent-grid-planning/tasks.json`.

The `tool-track/` package contains the preregistered, non-participant benchmark
for the GEAR tool paper: research questions, protocol, representative workflow
corpus, seeded faults, reproducible runners, and generated result schemas.
