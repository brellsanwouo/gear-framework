# P1 / T1 — Training: simple sequential scheduling

## Objective

Build a simple conference programme through a two-agent sequential workflow. This training task is not measured and receives no user input at runtime.

## Situation

The conference runs from 09:00 to 12:00 in one room, `MainHall`. The presentation order is fixed: `Reliable AI Systems` by Alice Martin (40 minutes), then `Efficient Scientific Workflows` by Bruno Lee (40 minutes), then `Reproducible Experiments` by Carla Diaz (45 minutes). A break occupies `MainHall` from 10:20 to 10:40. All speakers are available throughout the conference.

## Agents

![P1 architecture](/data/ConferenceScheduling/images/P1.svg)

### `ConferenceContextAgent`

- Purpose: `present the conference situation and its factual information.`
- TaskDescription: State only the conference hours, room, ordered presentations, speakers, durations, break, and availability facts. Do not formulate the scheduling problem, propose a solution, construct a programme, or explain the next agent.
- ExpectedOutput: A complete factual conference brief, with no schedule.

### `SchedulePlannerAgent`

- Purpose: `build a valid conference schedule.`
- TaskDescription: From the context output, assign a start and end time to every presentation. Preserve the stated order, keep every item inside conference hours, and do not overlap the fixed break.
- ExpectedOutput: A Markdown table with `Start`, `End`, `Room`, `Presentation`, and `Speaker` columns.

## Orchestration

- Mode: sequential
- Order: `ConferenceContextAgent -> SchedulePlannerAgent`
- Data flow: the complete output of `ConferenceContextAgent` is the only initial input to `SchedulePlannerAgent`.
- Runtime input: none
