# Interface de génération CrewAI

## Usage rapide

- Ouvrir [crewai-ui/index.html](crewai-ui/index.html) dans un navigateur.
- Renseigner les champs.
- Copier ou télécharger le YAML CrewAI généré.

## Source des mappings

L’interface charge automatiquement la binding table depuis [binding_table_for_agent.yml](../binding_table_for_agent.yml). Si le fichier n’est pas accessible, un mapping par défaut est utilisé.
